# 工数の記入漏れチェック — 使い方

## 1. 導入して開く（2分）

1. Atlassian Marketplace からインストールします
2. Jira のプロジェクトを開き、プロジェクトページの **Missing Worklog Check** タブを開きます
3. 今月ぶんの検査が自動で走ります

開くプロジェクトの**プロジェクト管理者**である必要があります。
「誰が入れていないか」が並ぶ画面なので、それ以外の人には表示しません。
権限を確認できない場合は、推測せず何も表示しません。

## 2. 結果の読み方

選んだ期間について、4つの数字が出ます。

| 数字 | 意味 |
|---|---|
| 記入が無い日 | 稼働日なのに、その人の記録が0時間 |
| 記録が薄い日 | 稼働日だが、記録が基準時間を下回っている |
| 工数の付いていない稼働課題 | 期間内に更新されているのに工数の記録が無い課題 |
| 取り戻せる可能性のある工数 | 記入が無い日は基準時間、薄い日は基準との差、を足したもの |

一覧は新しい日付順です。本人がまだ覚えている直近の漏れから潰せます。

## 3. 期間の選び方

**今月**・**先月**は1クリック。それ以外は日付を直接指定します。

どの期間でも次の2つが効きます。

- **未来は漏れに数えない。** 今日が21日なら、今月全体を選んでも検査は21日で止まります
- **その人の初回記録日より前は漏れに数えない。** 途中から参加した人が、
  月初の空白で埋まることはありません

## 4. 設定

- **1日の基準時間** — 「記入が無い日」と「薄い日」の両方で使います。既定は8時間
- **稼働曜日** — 既定は月〜金。外した曜日は漏れとして出ません
- **除外する人** — 名前の横の「対象から外す」で除外します。設定は残るので、
  退職者や短時間勤務の人は翌月も除外されたままです

設定はプロジェクトごとです。

## 5. エクスポート

エクスポート欄は CSV のテキストです。選択してコピーし、Excel やメールに貼り付けます。
プロジェクト・期間・検査日時と、検出1件につき1行が入っています。

## 6. アプリに見えるもの・見えないもの

- 課題と工数は検査のたびに Jira から**その場で**読みます
- **何も書き換えられません**。読み取り権限しか持っていません
- 保存するのはプロジェクトの設定（基準時間・稼働曜日・除外した accountID）だけです。
  氏名・課題・工数は保存しません
- アプリが属さないロールに限定された工数は Jira がアプリに返さないため、
  その工数だけの日は「漏れ」に見えることがあります
- 期間内にそのプロジェクトで一度も工数を入れていない人は、行として出ません
  （対象者を「入れた人」から作っているためです）
- 祝日は内蔵していません。曜日を外すか、その行は想定内として読んでください

## 7. 困ったとき

**「プロジェクト管理者のみ閲覧できます」と出る**
そのプロジェクトの管理者でないか、Jira が権限を返しませんでした。管理者に開いてもらってください。

**工数を入れた日が「漏れ」と出る**
その工数に表示制限が付いていないか確認してください。アプリは制限付きの工数を読めません。

**祝日が漏れとして出る**
稼働日は曜日で決まります。その曜日を外すか、その行は無視してください。

**「件数が多いため打ち切った」と出る**
検出が300件を超えました。期間を狭めてください。
